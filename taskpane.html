How it works
  1. In WordPress: Users → Profile → Application Passwords. Create a new app password (e.g. "Word Add-in").
  2. Enter your WordPress URL, username, and the application password above. Click Save.
  3. Click Publish to WordPress to create a draft post directly via the REST API.
  4. Use Update Application Password when you need to change or rotate your credentials.
