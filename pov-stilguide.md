# POV International – Redaktionel stilguide

*Udledt af analyse af 20+ artikler på tværs af alle kategorier, april 2026*

---

## 1. Artikeltyper og genrekoder

Alle artikler indledes med en genrekode i **versaler** efterfulgt af to skråstreger og en genrebetegnelse. Denne kode placeres i **fed** som del af manchetten/indledningen.

| Genrekode | Bruges til |
|---|---|
| `NYHED // OVERBLIK` | Faktuelle nyhedsartikler (POV Overblik-serien) |
| `UDLAND // BAGGRUND` | Udenrigsanalyse med korrespondentvinkel |
| `UDLAND // ANALYSE` | Dybdegående udenrigsanalyse |
| `DEMOKRATI // KRONIK` | Kronikker om demokrati og politik |
| `STRESS // KRONIK` | Kronikker om liv og samfund |
| `GLOBALT UDSYN // KRONIK` | Rejse- og globale perspektivkronikker |
| `FILM // ANMELDELSE` | Filmanmeldelser |
| `BØGER // ANMELDELSE` | Boganmeldelser |
| `MUSIK // ANMELDELSE` | Musikanmeldelser |
| `TEATER // ANMELDELSE` | Teateranmeldelser |
| `KULTURLISTEN // KLUMME` | Kulturredaktionens ugentlige anbefalingsklumme |
| `[EMNE] // ESSAY` | Essays |
| `[EMNE] // KLUMME` | Personlige klummer |
| `[EMNE] // ANALYSE` | Analytiske artikler |
| `[EMNE] // INTERVIEW` | Interviews |
| `[EMNE] // PORTRÆT` | Portrætter |

Mønsteret er altid: `EMNE // GENRE` — aldrig omvendt, aldrig uden dobbeltskråstreg.

---

## 2. Manchet / indledende resumé

### Nyhedsartikler (POV Overblik)
- De første **to afsnit** er sat i **fed** og fungerer som nyhedsmanchet
- Manchetten indledes med genrekoden: `**NYHED // OVERBLIK –**`
- Manchetten er selvbærende: den opsummerer de vigtigste fakta og kan læses alene
- Typisk 2–4 sætninger pr. manchetafsnit

### Kronikker og debatindlæg
- Første afsnit i **fed**, indledt med genrekode
- Manchetten opsummerer skribentens hovedpointe og nævner typisk forfatterens navn og titel
- Eksempel: `**DEMOKRATI // KRONIK – Danmark positionerer sig … skriver Regitze Rohlfing, vicedirektør i Nyt Europa**`

### Anmeldelser
- Første afsnit i **fed**, indledt med genrekode
- Manchetten sætter tonen og angiver anmelderens overordnede vurdering

### Debatindlæg / holdningsartikler
- Altid efterfulgt af standarddisclaimer: *"Dette indlæg er udtryk for skribentens holdning. Alle holdninger, som kan udtrykkes inden for straffelovens og presseetikkens rammer, er velkomne, og du kan også sende os din mening her."*

---

## 3. Overskrifter

- **Rubrik:** Direkte, informativ. Nyhedsrubrikker er typisk sætningsformede eller kolon-konstruktioner. Eksempler:
  - *"Energiagentur advarer: Europa kan løbe tør for flybrændstof i juni"*
  - *"Bookingdata misbrugt i ny svindelbølge mod hotelgæster"*
  - *"Biden i Mellemøsten: Stort postyr med små resultater"*
- **Mellemrubrikker (H2):** Bruges aktivt i lange artikler til at strukturere indholdet. Korte, ofte nominalfrasen eller spørgende. Ingen punktum.
- **Underrubrik:** Bruges sjældent som selvstændig HTML-element; manchetten overtager denne funktion.

---

## 4. Citater og direkte tale

### Anførselstegn
- Danske anførselstegn: `"tekst"` (ikke engelske "curly quotes" eller franske guillemets)
- Komma placeres **uden for** det afsluttende anførselstegn: `"tekst",` **ikke** `"tekst,"`
- Eksempler fra POV's egne artikler:
  - `"I Europa har vi måske seks uger eller deromkring tilbage af flybrændstof", siger han.`
  - `"Vi har en mulighed for at nå en historisk fredsaftale med Libanon", sagde han.`

### Citatformat
- Stående citater i brødteksten: ingen kursivering, ingen indrykning
- Udtrukne citater (pull quotes / blockquotes): bruges indimellem med `>` og kursiv i visse artikler, men dette er ikke standard i nyhedsartikler
- Citatattribution: `"[citat]", siger/sagde [navn].` — verbet **efter** citatet, ikke foran
- Foranstillet attribution: `Ifølge [navn] …` eller `[Navn] siger til [medie], at …`

### Enkeltord i anførselstegn
- Bruges til termer, begreber eller ironi: `en "systemisk" mangel`

---

## 5. Tegnsætning og typografi

- **Tankestregem (–):** Bruges som parentetisk tankestreg med mellemrum på begge sider: `tekst – tekst`. Ikke bindestreg (-) og ikke den lange em-dash (—) uden mellemrum.
- **Kolon efter sætning foran citat:** Ikke standard i POV's nyhedsartikler. Direkte tale introduceres med punktum: `sætter tal på situationen. "Citat"` — **ikke** kolon.
- **Kursiv:** Bruges til bogtitler, filmtitler, fremmedord og vægtlægning i essays/kronikker. Bruges **ikke** til direkte citater i nyhedsartikler.
- **Fed tekst i brødteksten:** Bruges udelukkende i manchet/indledende resumé — aldrig til at fremhæve enkeltord i brødteksten.
- **Procenttegn:** `procent` skrives ud som ord: `75 procent`, ikke `75%`
- **Tal:** Ettallene til og med tolv skrives ud som ord i løbende tekst; derover bruges cifre. Undtagen i direkte citat og statistik.

## 6. Sprog og stil

### Generelt register
- Klart, journalistisk dansk uden unødige fremmedord
- Faktuelle artikler: saglig, kortfattet, ingen stilistiske udsvævelser
- Kronikker/essays: personlig stemme tilladt, gerne med litterære greb
- Anmeldelser: analytisk-personlig tone; anmelderen argumenterer og begrunder

### Ord og fraser der undgås
- Anglicismer: `monitorere` → `overvåge`; `persistere` → `fortsætte` / `vedblive`
- Latiniserede/kunstige verber der er fremmedartede på dansk
- Opsvulmede konstruktioner: undgå at afslutte sætninger med indlysende tilføjelser (`"hvilket er en stor del"`, `"og det er ikke nok til at løse problemet fuldstændigt på nuværende tidspunkt"`)
- Hægtet-på-led: undgå slutled der ikke tilføjer ny information (`"og det ville være meget problematisk for rejsende"`)

### Foretrukne ord og konstruktioner
- `overvåge` (ikke `monitorere`)
- `fortsætte` / `vedblive` (ikke `persistere`)
- `gennem` (ikke `igennem` i standardkontekster)
- `jetbrændstof` som sammensætning (ikke `jet fuel` adskilt)
- `konflikten` frem for `krigen` ved ikke-erklærede krige (stilistisk valg i nyhedssammenhæng)

## 7. Kildeattribution

- Bureaukilderne nævnes fuldt ud ved første omtale: `nyhedsbureauet AP`, `Reuters`
- Ekspertkilder introduceres med navn + institution + kontekst: `Amaar Khan, der følger markedet for flybrændstof i analysehuset Argus Media`
- Myndighedskilder: `EU-Kommissionen oplyste …`, `Det Internationale Energiagentur vurderer …`
- Sekundær kildeattribution: `Ifølge Reuters …`, `Ifølge BBC …`
- Links til primærkilder samles som `Læs mere hos [kilde]`-sektion nederst i artiklen

---

## 8. Strukturelle konventioner

### Nyhedsartikler (POV Overblik)
1. Genrekode + fed manchet (2 afsnit)
2. Uddybning med baggrund og kontekst
3. Direkte citater fra primærkilder (typisk 1–3 citater)
4. Analyse/konsekvenser
5. Reaktioner (myndigheder, brancheorganisationer, virksomheder, eksperter)
6. Afsluttende ekspertvurdering
7. `Læs mere hos [kilde A], [kilde B]` — interne links til relaterede artikler undgås i brødtekst

### Kronikker og debatindlæg
1. Genrekode + fed manchet med forfatternavn og titel
2. Disclaimer om holdningsartikel
3. Brødtekst med mellemrubrikker
4. Forfatterbio nederst

### Anmeldelser
1. Genrekode + fed manchet med anmelderens overordnede vurdering
2. Faktaboks (for film: titel, genre, år, varighed, instruktør, medvirkende, premiere)
3. Anmeldelsestekst med mellemrubrikker
4. Tags/nøgleord nederst
5. Forfatterbio

---

## 9. Metadataformat

- **Dato:** `DD.MM.ÅÅÅÅ` (fx `17.04.2026`)
- **Kategori:** vises som `[Primærkategori]·[Sekundærkategori]`
- **Læsetid:** `Læsetid  X min.` (to mellemrum mellem "Læsetid" og tallet er et CMS-artefakt)
- **Forfatterbyline:** `[Fornavn Efternavn]` + eventuelt titel på næste linje

---

## 10. Fotocredits

Standard format: `[Beskrivelse]. Foto: [Navn], via [Kilde]`
Eksempler:
- `Israelske soldater på patrulje i det sydlige Libanon. Foto: IDF, via WikiMedia Commons`
- `Den internationale lufthavn i Wien, 18. marts 2019. Foto: Stanislav Doronenko, via WikiMedia Commons`

---

## 11. Særligt for korrekturlæseren (LLM-instrukser)

Disse regler skal altid overholdes og har højere prioritet end generelle sproglige forbedringer:

1. **Bevar genrekoden** præcis som skrevet — ret aldrig `NYHED // OVERBLIK` til andet
2. **Rør ikke citater** — alle ord inden for anførselstegn er ukrænkelige
3. **Kommaet hører uden for** det afsluttende anførselstegn på dansk: `"tekst",` — aldrig `"tekst,"`
4. **Ingen kursiv på citater** i nyhedsartikler
5. **Ingen koloner** foran direkte tale, medmindre de allerede er der — POV bruger punktum
6. **Fed tekst kun i manchetten** — aldrig i brødteksten
7. **Ændr ikke `krigen`/`konflikten`** og lignende redaktionelle ordvalg — disse er bevidste
